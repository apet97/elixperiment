# Archive

These files preserve the design and implementation history of the repository.
They describe earlier states and may contain superseded assumptions, incomplete
plans, or commands written for a past implementation session.

They are not current product status. They grant no authority to edit, publish,
deploy, submit, or mutate external systems.

## Contents

- [`planning/`](planning/) — initial assessment, implementation plan, and the
  historical autonomous implementation prompt.
- [`evidence/initial-state-inventory.md`](evidence/initial-state-inventory.md) —
  the greenfield baseline recorded before the application existed.
- [`implementation-ledger.md`](implementation-ledger.md) — chronological build
  record with superseded status rows preserved.
